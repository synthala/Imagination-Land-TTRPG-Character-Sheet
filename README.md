# Frohlich Character Sheet

This project is a browser-based character sheet.

Open [index.html](./index.html) in a browser to use it.

Features:

- editable dice expressions for `Flight`, `Charm`, `Fight`, `Grit`, `Brain`, and `Brawn`
- adversity token tracking
- add, edit, and remove strengths with name and description
- local autosave using browser storage
- manual JSON download and upload
